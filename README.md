V免签  —— 个人开发者收款解决方案
===============

> 本仓库为 [szvone/vmqApk](https://github.com/szvone/vmqApk)（原作者：vone）的**维护分支**，原版已不再维护。
> 修复内容：新版支付宝/微信通知解析（title+content 双字段 + 金额提取防广告数字误判），更新日志见 [CHANGELOG.md](CHANGELOG.md)。

V免签 安卓监控端：监听手机通知栏的收款提醒，自动推送至服务端完成订单回调。配合 PHP 服务端实现免签收款：

+ 收款即时到账，无需进入第三方账户
+ 免 root、免 xp 框架，不修改微信/支付宝客户端，防封更安全
+ 可用安卓备用机/模拟器挂小号收款，方便 iOS 用户
+ 免费、开源

> PHP 版服务端地址（维护分支）：https://github.com/BUGJI/vmqphp
> bug 反馈请建立 issues

## 安装

1. 下载 APK 安装（本分支签名与原版不同，**升级安装需先卸载旧版**，重装后需重新配置）
2. 打开 App，配置服务端地址与通讯密钥（可扫码配置）
3. 点击「开启服务」→ 在系统辅助功能中开启通知使用权
4. 返回 App 点击「检测监听权限」，显示正常即安装完毕

## 注意

+ 本系统原理是监控收款后手机的通知栏推送，请保持微信/支付宝/监控端后台运行，并加入内存清理白名单
+ 监控端不兼容所有手机，异常时请更换手机或使用模拟器挂机
+ 仅面向个人开发者，不适合商用多用户场景（商用请二次开发）
+ 若监听权限正常但仍不推送，请确认微信已关注「微信支付」「微信收款助手」两个公众号
+ 新版支付宝收款文案已从通知内容挪到标题，本分支 v1.1.0 起已兼容
